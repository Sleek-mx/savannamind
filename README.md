# Savanna Mind Learn — Interactive Platform

Interactive AI learning and training platform for Savanna Mind's first pillar ("Learn"), built for training African and Kenyan learners to integrate AI into daily workflows.

## Features
- **Zero-Emoji Architecture**: Standardized on Lucide SVG vector iconography.
- **Age-Tiered Onboarding**:
  - Ages 8–12: Grade 3–6 CBC foundational logic & pattern recognition.
  - Ages 13–17: JSS & High school algorithmic thinking & digital fact-checking.
  - Ages 18+: Professional sector tracks (Agri-Business, Healthcare/CHPs, Micro-SMEs/Dukas, Education/CBC, Tech, Creative Media).
- **Proactive AI Sidekick ("Kibo")**: 3D-shaded cheetah mascot with inactivity detection (>14s pause) and contextual multi-dialect tutoring (English, Kiswahili, Sheng).
- **Localized Kenyan Realities**: Murang'a tomato blight diagnosis, Gikomba WhatsApp commerce, Machakos Community Health Promoter TB screening, M-Pesa automated transaction verification.
